# TaskFlow

TaskFlow junior developer-lərin praktiki inkişafı üçün hazırlanmış kodbazadır.

Layihənin inkişafı junior roadmap-ımıza əsasən mərhələli şəkildə davam edir.

## Roadmap-da yeri

TaskFlow junior roadmap-da Laravel və Nwidart mərhələsinin praktiki layihəsidir. Məqsəd öyrənilən bilikləri real daxili panel üzərində tətbiq etmək, düzgün kod quruluşu və komanda işi vərdişləri qazanmaq, daha sonra isə digər mərhələyə hazırlaşmaqdır.
